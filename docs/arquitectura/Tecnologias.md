# Tecnologías del Proyecto

## Backend y servicios

| Componente | Tecnología |
|---|---|
| API Gateway | Java + Spring Boot |
| Auth Service | Java RMI |
| File Service | Java |
| Sync Service | Java + Sockets |
| Photo Service | PHP |
| Streaming Service | PHP + SOAP |
| Monitoring Service | Go + gRPC |
| HPC Service | C + OpenMPI |

## Clientes

| Cliente | Tecnología |
|---|---|
| Web | HTML, CSS, JavaScript |
| Desktop | JavaFX |
| Mobile | Kotlin |

## Datos

| Componente | Tecnología |
|---|---|
| Base de datos | PostgreSQL |
| Archivos | Shared Storage |
