R-09 - Android almacena contraseña en SharedPreferences sin cifrado
Fecha: 2026-09-11

RIESGO ORIGINAL

CredentialStore persistía directamente:

username
password

mediante SharedPreferences.

La contraseña era almacenada en texto claro mediante una operación
equivalente a:

putString(KEY_PASSWORD, password)

Esto permitía recuperar la credencial si el almacenamiento privado
de la aplicación era comprometido.

MITIGACIÓN

CredentialStore fue migrado a cifrado autenticado mediante:

Android Keystore
AES-256
GCM
NoPadding
Tag GCM: 128 bits

Transformación utilizada:

AES/GCM/NoPadding

La clave criptográfica se crea y conserva mediante:

AndroidKeyStore

Alias:

upb_sync_credentials_aes

La clave AES no se almacena en:

- código fuente;
- SharedPreferences;
- archivos del repositorio.

ALMACENAMIENTO ACTUAL

SharedPreferences conserva:

username
password_ciphertext
password_iv

La contraseña plaintext no se persiste.

MIGRACIÓN DE INSTALACIONES ANTIGUAS

Se conserva temporalmente el identificador legacy:

password

únicamente para detectar datos generados por versiones anteriores.

Si CredentialStore encuentra una contraseña legacy:

1. la lee una vez;
2. la cifra mediante Android Keystore + AES-GCM;
3. persiste ciphertext e IV;
4. elimina la entrada plaintext legacy.

No existe fallback que vuelva a guardar la contraseña sin cifrado.

MANEJO DE CLAVE INVALIDADA

Si el ciphertext existe pero la clave Keystore ya no puede descifrarlo,
CredentialStore elimina el material cifrado inválido y obliga a
configurar nuevamente las credenciales.

BACKUP

AndroidManifest configura:

android:allowBackup="false"

Por tanto, el almacenamiento de credenciales no está habilitado para
backup de aplicación.

VALIDACIÓN ESTÁTICA

No se detectó escritura directa de password a SharedPreferences.

No se detectó:

SecretKeySpec
clave AES hardcodeada
material criptográfico privado embebido

La cadena "password" restante corresponde únicamente a la clave
legacy utilizada para migración.

VALIDACIÓN DE COMPILACIÓN

:app:compileDebugKotlin
Resultado: BUILD SUCCESSFUL
Exit code: 0

:app:assembleDebug
Resultado: BUILD SUCCESSFUL
Exit code: 0

LIMITACIÓN DE VALIDACIÓN

No se dispone actualmente de dispositivo Android físico y no se utiliza
emulador por decisión del entorno de pruebas.

Por esta razón, la integración con Android Keystore está validada mediante:

- revisión estática;
- compilación Kotlin;
- construcción APK;
- verificación de configuración.

La prueba runtime de creación, cifrado, descifrado y migración del
Keystore deberá repetirse posteriormente en un dispositivo Android físico.

RESULTADO

R-09 MITIGADO
